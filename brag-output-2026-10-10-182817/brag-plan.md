# Brag Plan: Chaty

## What is this app?
Chaty is a private, customizable, production-ready communication application with military-grade RFC 9420 MLS End-to-End Encryption for messaging, tasks, and crystal-clear WebRTC voice/video calls.

## The angle
Showcase how Chaty combines enterprise security with beautiful, intuitive design - proving that private communication doesn't have to look or feel clinical or complicated.

## Hook (first 2-3 seconds)
A lock icon animates open to reveal the Chaty app interface, with the text "Your conversations. Actually private." appearing as the lock fully opens.

## Key moments (the middle)
- Watch a message send with real-time encryption indicators showing MLS key ratcheting in action
- See a seamless transition from chatting to initiating a crystal-clear WebRTC video call
- Observe the beautiful, fluid UI animations as chat bubbles appear with perfect timing

## Outro / punchline
The Chaty logo appears with the tagline: "Private by design. Beautiful by choice."

## User flow worth showing
Open app → Send encrypted message with visible security indicators → Receive and read message with delivery/read receipts → Initiate video call → See calling interface

## Tone
- Preset: polished
- Creative direction: quiet premium product film
- Interpretation: Fewer scenes, longer holds. Confidence through restraint - letting the quality of the product speak for itself rather than relying on flashy effects.

## Format: landscape — 1920x1080
## Duration: 18 seconds

## Visual identity (from the project)
- Background: #FFFFFF (clean white from WhatsApp Light theme)
- Accent: #25D366 (WhatsApp green)
- Text: #111B21 (WhatsApp dark charcoal)
- Display font: System sans-serif (clean, readable)
- Body font: System sans-serif
- Strongest visual element: The WhatsApp-inspired clean design language with chat bubbles and call interface

## Share copy (draft)
Chaty: Where military-grade encryption meets beautiful design. Your conversations, actually private.

## Audio direction
- Role: warm professional bed with subtle UI motion-matched accents
- Music: Light, professional ambient track (think modern corporate but warm)
- Music treatment: Start at -3s (pre-roll), fade in over first 0.5s, maintain -18dB volume, subtle swell on key moments
- Music cue guidance: Using ambient professional bed - cues to be detected at composition time for message send (4s), call initiation (10s), and logo reveal (16s)
- Audio-reactive treatment: subtle; use music RMS to make UI elements gently pulse/pop with key actions
- SFX posture: sparse, professional, motion-matched (soft taps for button presses, subtle whooshes for screen transitions)
- Audio-coupled moments: message send confirmation (4s), call connect tone (10s), logo chime (16s)
- Restraint rule: Audio must never overpower or distract from the clean visual presentation - it should feel like a premium product video, not an advertisement

## Storyboard

### Scene 1 — Lock Reveal — 3s
[What's on screen. Black screen. A locked padlock appears in center. The lock shackle animates upward and opens.]
Sequential/interaction: Lock shackle rising and opening
Audio intent: Anticipation building, then satisfaction of opening
Audio-coupled idea: Lock click sound on opening, subtle whoosh as shackle rises
Music: Professional ambient bed fading in
Transition mood: Soft crossfade → Scene 2

### Scene 2 — App Reveal — 2s
[What's on screen. The Chaty app interface fades in where the lock was. Clean chat list visible with WhatsApp-inspired design.]
Sequential/interaction: App interface fading in
Audio intent: Clean, confident reveal
Audio-coupled idea: Soft chime as app settles into place
Music: Ambient bed continuing
Transition mood: Crossfade → Scene 3

### Scene 3 — Messaging Flow — 6s
[What's on screen. Chat interface opens. User types "Hey, this is actually private" - text appears with typing indicator. Message sends with small MLS encryption badge appearing next to timestamp. Delivery ticks appear (single → double → colored double).]
Sequential/interaction: Text typing character by character, message sending animation, delivery tick progression
Audio intent: Focused, productive, reassuring
Audio-coupled idea: Subtle key ticks as text types, soft "whoop" on message send, gentle ticks as delivery receipts update
Music: Ambient bed continuing, slight swell on message send
Transition mood: Crossfade → Scene 4

### Scene 4 — Calling Flow — 5s
[What's on screen. From chat, user taps video call button. Calling interface appears with outgoing call animation. Call connects and splitscreen shows both users (simulated).]
Sequential/interaction: Button press animation, calling screen transition, call connection animation
Audio intent: Clear, professional, connected
Audio-coupled idea: Button tap sound, ringing tone (2 rings), connect chime
Music: Ambient bed continuing, gentle swell on call connect
Transition mood: Crossfade → Scene 5

### Scene 5 — Outro — 2s
[What's on screen. Screen fades to white. Chaty logo appears in center. Tagline "Private by design. Beautiful by choice." fades in below.]
Sequential/interaction: Logo appearing, then tagline fading in
Audio intent: Confident, concluding, memorable
Audio-coupled idea: Soft musical chime on logo appearance, gentle tone on tagline
Music: Ambient bed continuing, gentle fade-out starting at 17s
Transition mood: None (end)

**Music mood for this video:** warm professional ambient
**Audio summary:** A warm, professional ambient audio bed that stays subtle and supportive, with precise sound effects that match UI interactions to create a feeling of polished, confident professionalism.
